--------------------------------------------------------------------------------
2. SKIPPED EXPERIMENTAL COMMITS (REASON FOR EXCLUSION)
--------------------------------------------------------------------------------
- 261eeb9c1585 ("f2fs: introduce checkpoint_merge mount option"):
  From Linux 5.13. Requires separate kernel thread management that conflicts with
  Android Userspace Checkpointing (checkpoint=disable/checkpoint=enable) and triggers
  NULL pointer dereference during early superblock initialization before segment manager is ready.
- 093749e296e2 ("f2fs: support age threshold based garbage collection - ATGC"):
  From Linux 5.11. Requires non-existent inmem-curseg and 64-bit extent caching APIs, causing
  victim selection signature mismatch and boot failures.
- 4f993264fe29 ("f2fs: introduce discard_unit mount option"):
  From Linux 5.16. Changes on-disk/in-memory bitmap layouts in build_sit_info that crash 5.4 kernels.
